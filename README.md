# Bank_churn_Predictions
Bank churn prediction project
Bank Customer Churn Prediction
📌 Project Overview

This project aims to predict whether a bank customer will churn (leave the bank) using Machine Learning techniques.

📊 Features Used
Credit Score
Age
Tenure
Balance
Number of Products
Credit Card Status
Active Membership
Estimated Salary
Geography
Gender
🔍 Exploratory Data Analysis (EDA)

Key insights:

Customers aged above 40 are more likely to churn
Inactive members have higher churn rate
Germany shows higher churn compared to other regions
Customers with fewer products tend to leave
🤖 Machine Learning Model
Algorithm: Logistic Regression
Accuracy: ~85%
Preprocessing: Encoding + Scaling
🌐 Streamlit App

An interactive web app where users can input customer details and predict churn.

🚀 How to Run
pip install -r requirements.txt
streamlit run app.py
